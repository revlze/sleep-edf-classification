# Исследовательский архив

Здесь сохранены исходники, конфигурации, notebook00–05 и окружения серий001–155.
Результаты и данные физически сохранены в локальных data/, artefacts/, submissions/,
рабочие заметки — docs/; содержимое этих каталогов игнорируется Git.

Финальная модель и точка запуска находятся в ../final/. Исторические notebook могут
клонировать закреплённые старые commits, в которых дерево проекта ещё начиналось в корне.
Для локальных исследовательских CLI запускайте процесс из archive/ или добавляйте
archive в PYTHONPATH. Параметры данных/кэшей передавайте явно. Полные серии не повторять.

Снимок исходного журнала до переезда — experiments.csv. Актуальный общий индекс в
корне репозитория содержит те же149 записей с обновлёнными путями.
Подробная научная история подготовлена в ../final/docs/research.md.
