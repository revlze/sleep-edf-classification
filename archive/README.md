# Исследовательская часть

Здесь сохранены реализации, конфигурации и notebooks этапа исследования.
Текущий воспроизводимый inference находится в [final](../final/README.md).

| Каталог | Что внутри |
|---|---|
| `src/` | Загрузка данных, EDA, признаки, модели и процедуры обучения |
| `configs/` | Эксперименты с общими глобальными ID |
| `notebooks/` | EDA, табличные модели и Kaggle launchers pretrained-серий |
| `environments/pretrained/` | Историческая среда Python 3.12 / PyTorch 2.6 |
| `pyproject.toml`, `uv.lock` | Историческая табличная среда Python 3.14 |

[Журнал](../experiments.csv) хранит исходные validation-метрики, время и статусы.
[Обзор исследования](../docs/experiments.md) объясняет контрольные точки и отрицательные результаты.
Поле `artefacts_path` указывает исторический локальный путь; большие результаты,
кэши, исходные данные и экспериментальные checkpoints не включены в Git.

Launchers отражают структуру и зависимости соответствующих этапов. Для повторения
исторического запуска может понадобиться его исходный commit и внешние данные/кэши.
Архив не является дополнительным финальным pipeline; для выбранной модели обучение
повторять не требуется.
