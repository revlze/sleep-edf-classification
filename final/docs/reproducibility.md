# Воспроизводимость

Финальное обучение не повторяется: загружаются опубликованные U-Sleep/AnySleep/Tiny веса и
сохранённые full-train refit checkpoints082/085/102/106. История обучения и configs
остаются в archive/. Tiny082 — частичный state: оригинальный Tiny checkpoint обязателен.

Два окружения сохранены намеренно. Сигнальный inference и heads использовали
Python3.12, Torch2.6, NumPy2.2.6/SciPy1.15.3/sklearn1.6.1. Исходный106-feature cache
создан в Python3.14, NumPy2.5.4/SciPy1.18.1/antropy0.2.3. Финал заново вычисляет
эти признаки из raw сигналов отдельным worker в исходном окружении, не читая старый cache.
В каждом окружении есть pyproject.toml, uv.lock и.python-version.

Состояние: исследовательские CSV существуют и были проверены при импорте. Готовый
Linux runtime прошёл холодное восстановление из ZIP внутри `unshare --net`: доступ
к сети отсутствовал, оба Python и пакеты восстановлены, настоящие веса выполнили
CPU inference четырёх эпох с обоими CSV. Свидетельство — offline/verification.json.
Полный финальный06 для157/113 наT4 ещё не выполнен;
точное совпадение всех66222 labels и ограничение2часа пока не подтверждены этим notebook.
В release_metadata.json неизвестные Kaggle submission IDs/версии публикаций оставлены null.

Настройки детерминизма: seed42, torch deterministic algorithms, выключенные CuDNN
benchmark/TF32, CUBLAS_WORKSPACE_CONFIG=:4096:8. Исходные batches не адаптируются
автоматически, preprocessing и порядок операций фиксированы. Один seed не считается
доказательством воспроизводимости: доказательство — полный pairwise id,label check.

submissions/ содержит выбранные CSV только как эталон сравнения. Код сначала выполняет
нейросетевой inference, записывает результат и затем сравнивает пары. Он не читает
эталонные метки при построении features/logits, не исправляет расхождения и не заменяет
свои ответы готовым файлом. SHA CSV может отличаться из-за оформления; решают пары id,label.
При несовпадении status=LABEL_MISMATCH, сохраняется диагностика и процесс завершается ошибкой.

Provided val многократно использован для разработки. AnySleep author train содержит6/8
наших validation людей по опубликованным split. Внешнее pretraining и downstream
subject CV — разные вопросы; улучшения не трактуются как независимая клиническая оценка.
Дополнительные12 людей из train служили диагностике, не независимой проверке:
TinyFT и heads обучались на нашем train. Основной выбор выполнен по provided validation.

Публичные notebook/Inputs должны быть сохранены точными версиями и доступны преподавателю.
Интернет используется только сборщиком offline Input заранее. Сам финальный notebook
запускается с Internet Off: Python, пакеты, код и веса приходят из закреплённых Inputs.
Загрузчик создаёт локальные venv без pip и распаковывает готовые site-packages;
проверяются SHA архивов, оба исходных lock-файла и все версии distributions.
Фиксируется время полного inference, GPU, версии библиотек, SHA весов и выходных CSV.
