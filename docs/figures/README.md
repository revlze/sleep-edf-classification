## Повторная генерация

Из корня репозитория:

```sh
uv run --script docs/figures/generate.py --data-root /path/to/full_psg_v1
```

Нужны `labels.csv`, `epochs/train/SC4011.npz` и `epochs/train/SC4092.npz` из
выданной поставки. При наличии данных в `data/` аргумент можно опустить.
По умолчанию рисунки сохраняются рядом с генератором; `--output-dir /path/to/figures`
позволяет выбрать другой каталог.

Скрипт использует Python 3.14 и фиксированные NumPy 2.5.4, SciPy 1.18.1,
Matplotlib 3.11.2 в отдельном окружении `uv`. Два окружения финального inference
и их lock-файлы не меняются. Из данных читаются только перечисленные открытые
источники; тестовые сигналы, метки и reference CSV генератору не нужны.
